# Documentación en LaTeX

Edita `main.tex` y haz doble clic en `compilar.bat` para generar y abrir `main.pdf`.

El compilador Tectonic 0.17.0 está instalado en `../.tools/tectonic/` dentro del proyecto. Necesita conexión a Internet cuando descarga paquetes por primera vez; después reutiliza su caché local.

También puedes compilar desde PowerShell, en la raíz del proyecto:

```powershell
.\.tools\tectonic\tectonic.exe .\DocTec\main.tex
```

Descarga oficial: https://github.com/tectonic-typesetting/tectonic/releases/tag/tectonic%400.17.0
